    Understanding Password Entropy
    What is Entropy?

    Entropy measures how unpredictable your password is, measured in bits. It's based on:

    • Password length
    • Character types used (lowercase, uppercase, numbers, symbols)
    • Randomness of the password

    Each bit of entropy doubles the search space, making brute-force attacks exponentially harder.
